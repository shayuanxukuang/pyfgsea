Four connected boxes show the TED workflow. Dynamic single-cell trajectories, perturbations, time courses or pathway scores with biological blocks enter event inference. TED estimates event family, timing and direction and audits matched state, controls and ambiguity. The result receives an event-support code from E0 to E2 and a validation-provenance code from V0 to V4. The final record states the supported interpretation, current evidence boundary and next validation, emphasizing that detection, artifact control and biological validation are separate auditable targets.
