# PyFgsea 0.2.0 release-candidate history

Release-candidate tags are fixed technical records. A failed or replaced
candidate keeps its original tag and run records; a later candidate receives a
new tag. None of the candidates below was published as final `0.2.0` on PyPI,
GitHub Releases, or Zenodo.

| Candidate | Repository history | Verification result | Status |
| --- | --- | --- | --- |
| `v0.2.0-rc1` | TED companion history; no common ancestor with official PyFgsea `main` | Not valid as official PyFgsea release ancestry | Replaced; tag retained |
| `v0.2.0-rc2` | TED companion history; no common ancestor with official PyFgsea `main` | Not valid as official PyFgsea release ancestry | Replaced; tag retained |
| `v0.2.0-rc3` | Official PyFgsea history | Windows package checks and both reference OCI profiles passed. Linux and macOS package checks failed because the CI toolchain lacked `rustfmt` and regenerated normal scores differed at platform-dependent binary64 tails. The summary check failed. | Replaced by RC4 |
| `v0.2.0-rc4` | Official PyFgsea history | Linux and Windows package checks and both OCI profiles passed. CI exposed an unpinned Ruff version and masked Windows step status; Python 3.9 rejected `Path.write_text(newline=...)`; macOS ARM failed two Figure 1 input tests after decimal-boundary drift. The summary check failed. | Replaced by RC5 |
| `v0.2.0-rc5` | Official PyFgsea history | The annotated-tag check, all three package checks, both OCI profiles, and the summary check passed. Eight of ten PR matrix jobs passed; Ubuntu and Windows Python 3.9 stopped while installing mypy 2.3.1, which requires Python 3.10 or newer. | Replaced by RC6 |
| `v0.2.0-rc6` | Official PyFgsea history | All ten PR CI jobs, the annotated-tag check, Linux/macOS/Windows package checks, both reference OCI profiles, and the summary check passed. | Verified; replaced by RC7 |
| `v0.2.0-rc7` | Official PyFgsea history | Updates the public documentation, Figure 2 parameter record, and reproduction names. The annotated tag starts the same package and reference-image checks. | Current candidate |

RC3 and later use the official PyFgsea ancestry that starts from commit
`2b047dc557604018b28d82fa3da9ab496e1955a4`. TED, BIB, T21, and other
companion-project code are outside the PyFgsea 0.2.0 release.

The RC6 verification records are:

- [PR CI run 33524333266](https://github.com/shayuanxukuang/pyfgsea/actions/runs/33524333266);
- [artifact and reference OCI run 33524240182](https://github.com/shayuanxukuang/pyfgsea/actions/runs/33524240182).

Passing a candidate's package and reference-image checks does not complete the
paper reruns. Figure 1, Figure 2, supplementary analyses, and the manuscript
comparison remain separate versioned runs.
