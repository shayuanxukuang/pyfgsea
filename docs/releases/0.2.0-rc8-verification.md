# PyFgsea 0.2.0rc8 verification

RC8 was built from annotated tag `v0.2.0-rc8` at merge commit
`ee5855bad7200655e580f44fdf4087bb1bad67b5`.

## Changes in this candidate

- [PR #3](https://github.com/shayuanxukuang/pyfgsea/pull/3) removed unfinished
  pipeline modules and the unsupported trajectory CLI, kept the implemented
  GSEA and trajectory interfaces, added a runnable trajectory example, and
  fixed explicit DPT-root handling.
- [PR #4](https://github.com/shayuanxukuang/pyfgsea/pull/4) prepared the
  `0.2.0rc8` version and updated the current release-candidate references.
